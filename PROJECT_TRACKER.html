🔧 Features v2.1 — Scraper & Bookmarklet
  • ✅ yad-il.co.il support — bookmarklet and scraper accept both Yad2 domains
  • ✅ Multi-query scan — scans all dehydratedState queries (fixes yad-il listing data in queries[1])
  • ✅ Rooms fallback chain — checks infoBar[], additional_info, details, regex scan
  • ✅ Multi-endpoint phone — tries 3 customer API endpoints for phone retrieval
  • ✅ Dynamic APP_URL — setup page generates bookmarklet pointing to current host
  • ✅ Graceful fallback — sends autoscrape=true when client-side parse fails
💬 Features v2.1 — Threaded Notes
  • ✅ Schema migration — notes column converted from TEXT to JSONB array
  • ✅ Note structure — {userId, userName, text, createdAt} per entry
  • ✅ NotesThread component — chat-style bubbles with author attribution and timestamps
  • ✅ Compact card view — shows last note preview with author name
  • ✅ Compose area — textarea + send button, Ctrl+Enter shortcut
  • ✅ Search — FilterToolbar searches inside note text entries
📷 Features v2.1 — Native Image Uploads
  • ✅ Supabase Storage — item-images bucket with public read, auth write policies
  • ✅ Upload utility — file validation (5MB limit, JPEG/PNG/WebP/GIF)
  • ✅ Hybrid support — mix external URLs (Yad2) + uploaded files in same images[] array
  • ✅ Image preview strip — thumbnails with hero selector and remove button
  • ✅ Upload progress — loading state and per-file error messages
👁️ Features v2.1 — Read Receipts
  • ✅ viewed_by column — JSONB array of user IDs added to apartments table
  • ✅ Auto-mark creator — creator's ID added to viewed_by on insert
  • ✅ ✨ NEW badge — pulsing amber badge on items not yet seen by current user
  • ✅ Mark on interact — fires markAsViewed when user opens card or reacts
  • ✅ GIN index — fast containment queries on viewed_by array
🔐 Features v2.0 — Authentication
  • ✅ Supabase Auth — Real email/password authentication replaces shared password
  • ✅ Signup with invite gate — Requires APP_PASSWORD to register (prevents strangers)
  • ✅ Login page — Email/password form with error handling
  • ✅ Session management — Secure httpOnly cookies via @supabase/ssr
  • ✅ Middleware auth guard — Protects routes, redirects unauthenticated users
  • ✅ Auto-create profile — Database trigger creates profile on signup
🏠 Features v2.0 — Households
  • ✅ Onboarding flow — Create new household or join existing one
  • ✅ Create household — Pick name, category, optional custom invite code
  • ✅ Join household — Enter partner's invite code to join
  • ✅ Invite codes — Auto-generated (8-char hex) or custom (4+ alphanumeric)
  • ✅ Edit invite code — Change anytime from settings (pencil icon)
  • ✅ Copy invite code — One-click copy to clipboard
  • ✅ View members — See all household members in settings
  • ✅ Household info in navbar — Name, category badge, member count
🎨 Features v2.0 — Multi-Category
  • ✅ Category selection — Choose: 🏠 Apartments, 👰 Wedding Venues, or 🚗 Cars
  • ✅ Dynamic form fields — Fields change based on category type
  • ✅ Category-specific metadata — Stored in flexible JSONB column
  • ✅ Dynamic labels — "Add Apartment" vs "Add Venue" vs "Add Car"
  • ✅ Category badges on cards — Year/mileage for cars, distance for venues
  • ✅ Conditional fields — Rooms only for apartments/venues, not cars
