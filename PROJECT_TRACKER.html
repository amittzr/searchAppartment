✅ Features Implemented
  • ✅Add apartment — modal form with field validation
  • ✅Edit apartment — pre-filled modal
  • ✅Delete apartment — 2-step confirmation dialog
  • ✅Status reactions: Liked ❤️ / Review Later 🤔 / Rejected ❌ (toggle, click again to reset)
  • ✅Filter tabs with live counts: All / Liked / Review / Rejected
  • ✅Real-time sync via Supabase Realtime — instant updates for both users
  • ✅Auto-detect listing source: Yad2 / Facebook from URL
  • ✅Direct link to original ad (opens in new tab)
  • ✅Phone number click-to-call
  • ✅Seller/contact name display on cards
  • ✅Shared notes per apartment
  • ✅Responsive mobile-first design
  • ✅Loading skeleton (shimmer cards)
  • ✅Empty state (per-filter + global)
  • ✅Error handling with dismissible banners
  • ✅Shared password authentication (httpOnly cookie, 7-day session)

  • ✅?from= redirect after login
  • ✅CI/CD — push to main → auto-deploy on Vercel

⚠️ Known Limitations
  • ⚠️No per-user auth — both partners share one password and see identical data
  • ⚠️Image URLs are user-supplied — broken links show a placeholder icon
  • ⚠️No rate limiting beyond 500ms delay on wrong password attempts
  • ⚠️Supabase free tier pauses after 1 week of inactivity — resume from dashboard
