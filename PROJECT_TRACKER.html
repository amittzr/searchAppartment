✅ Features v1.0-v1.1 (Core)
  • ✅ Add/Edit/Delete apartments with modal forms
  • ✅ Real-time sync via Supabase Realtime
  • ✅ Yad2 auto-fill — paste URL to extract all data
  • ✅ Bookmarklet for one-click save from Yad2
  • ✅ Expandable card with photo gallery
  • ✅ Phone click-to-call + seller name display
  • ✅ Password authentication with httpOnly cookies
💕 Features v1.2 (Multi-Household & Reactions)
  • ✅ household_id field for multi-tenant isolation
  • ✅ HouseholdContext with localStorage persistence
  • ✅ HouseholdSettingsModal for configuring names
  • ✅ Per-user reactions — each partner marks independently
  • ✅ Dual reaction badges on cards (both partners' status)
  • ✅ Match indicator 💕 when both partners like same apartment
  • ✅ rooms field extracted from Yad2
  • ✅ FilterToolbar: search, rooms filter, sort, reaction pills
  • ✅ Reaction filters: All, Both Liked, I Liked, Partner Liked, Review, Rejected, Unsorted
🗺️ Features v1.3 (Interactive Map)
  • ✅ Map button in header to open full-screen map view
  • ✅ Leaflet map loaded from CDN (no npm dependency)
  • ✅ OpenStreetMap tiles (free, no API key)
  • ✅ Auto-geocoding addresses using Nominatim API
  • ✅ latitude/longitude stored in database
  • ✅ Color-coded markers: Pink Both liked, Red Liked, Blue No reaction, Gray = Rejected
  • ✅ Hover tooltips showing address and price
  • ✅ Click marker → mini apartment card with image, price, actions
  • ✅ Legend explaining marker colors
